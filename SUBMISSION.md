# Submission — Tank Platoon Tournament (AP6416)

**Repository**: https://github.com/yikedi/6416AITank
**Branch**: `main`

Clone it, open the project in **Unity 2022.3.39f1**, load `Assets/Scenes/MainAI.unity`, and press Play.

Notes:

- No Git LFS needed — a plain `git clone` is complete.
- `exportconfig.json` is included at the repository root, so match results export to `Excel/` out of the box.
- Player controls: **W / A / S / D** to drive and steer, **Space** to fire (hold to charge).
- Design document: [`AI-Design-Document-EN.md`](AI-Design-Document-EN.md)

All AI changes are confined to `Assets/Scripts/AI/**`; prefabs, scenes, `ProjectSettings` and `Packages` are unchanged from the provided baseline.
